# 家族旅行 tabi-log

一家四口的旅行紀錄，一趟一條路線。

🔗 網站：https://tabi-log.github.io/family-travel/

## 旅程

- **大阪京都行**：2025.06.23 – 06.28（5夜6天）
- **金門廈門**：2026.07.19 – 07.22（4天3夜，媽媽蛋奶素）
- **杭州之旅**：規劃中

## 網站內容

- 首頁：所有旅程依年份排列，規劃中的旅程排在最上面
- 旅程總覽：全程錨點看板、每日路線、實用資訊
- 每日看板：時間表、今天的重點、交通方式
- 景點與店家：依區域分類，附地圖連結；素食店家標示「素食可」
- 手機與電腦自動切換排版，手機用右上角「選單」切換旅程

## 後台

網址：https://tabi-log.github.io/family-travel/admin.html（建議用電腦開啟）

- 用 GitHub 金鑰登入（金鑰的 Repository access 要包含 family-travel）
- 上方可切換旅程、新增旅程；每日行程可新增或刪除天數
- 可修改照片配置、旅程資訊、景點區域、實用資訊、每日行程、今天的重點、交通、景點與店家
- 右側即時預覽，可切換電腦／手機；按「發布」後約 1–2 分鐘網站更新

## 檔案說明

- `index.html`：網站頁面與版型（海霧藍配色；標題用思源宋體＋Source Serif 4，內文用思源黑體＋Source Code Pro）
- `admin.html`：後台
- `data.js`：所有旅程的資料（SITE 首頁設定、TRIPS 各趟旅程、PHOTOS 照片庫）
- `photos/`：照片（`f` 開頭是大圖，`t` 開頭是縮圖）
