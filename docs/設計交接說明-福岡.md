# 設計交接說明：把「家族旅行」網站的風格套到福岡之旅

> 給 AI 的說明：這份文件描述一個已經完成、使用者很滿意的旅遊網站設計。
> 請把這套設計套用到「福岡之旅」網站上，**但完整保留福岡網站現有的所有內容與資料**。
> 參考網站（可直接打開看實際效果）：https://tabi-log.github.io/family-travel/

---

## 0. 工作守則（請先讀）

1. **內容一律保留**：行程、時間、地點、店家、照片、說明文字都不能刪改或自行編造。只改外觀與版面。
2. **先盤點、再提案、後動手**：
   - 先讀過福岡網站現有的檔案與資料結構，列出「現有內容 → 新版面放在哪裡」的對照表給使用者確認。
   - 使用者同意後才開始改。
3. **不知道就問**：資料裡沒寫的事實（例如去了哪家店、幾點集合），不要猜，列成問題問使用者。
4. **語言**：介面文字用台灣繁體中文。英文只當小標點綴，例如 `Prologue`、`Chapter 01`。
5. **手機優先**：每個改動都要在手機寬度（390px）和電腦寬度（1366px）各檢查一次，不能出現左右捲動。
6. **先預覽再上線**：改完先給使用者預覽，確認後才更新正式網站。

---

## 1. 設計理念

- **氛圍**：溫馨、淡淡流露的情緒，像一本手作旅行相簿；照片是主角，文字是陪襯。
- **故事感**：已結束的旅程要像一本書，有開場、每天一章、收尾，情緒慢慢遞進。
- **節奏**：適合的照片就滿版，其他的留白，不要每張都套同一種樣式。
- **立體感**：用柔和的暖色陰影、相片微微傾斜，營造放在桌上的實體感；不要用生硬的灰色陰影。
- **淡化背景**：用照片做極淡、往下漸隱的背景，營造氛圍。

## 2. 設計 Token

### 2.1 顏色（海霧藍，取自海面、港口、天空）

```css
:root{
  --bg:#F5F5F1;      /* 頁面底色：米白 */
  --paper:#FFFFFF;   /* 卡片、相紙 */
  --butter:#C6D6DC;  /* 主色塊（大圖右側的色塊、膠囊按鈕底色） */
  --butter-2:#E1EAEC;/* 淺色塊、hover 底色 */
  --line:#D5DCDC;    /* 細線 */
  --ink:#1F2E3A;     /* 主要文字、深色按鈕、頁尾底色 */
  --mute:#5E6B74;    /* 次要文字 */
  --soft:#8E9AA2;    /* 更淡的文字 */
  --sage:#5F7C8A;    /* 沒照片時的佔位色塊 */
  --rust:#B9603F;    /* 點綴色（連結、交通時間），少量使用 */
  --rust-soft:#F4E2D9;
}
```

> 主色可以依福岡照片的調性調整，但結構相同：一個淺主色塊＋深色文字＋少量點綴色。
> 我們的做法是先分析照片的顏色分布，再從照片裡最多的色系挑主色。

### 2.2 字體（全部是 Adobe「思源」同一家族，中英文才會協調）

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Source+Serif+4:ital,opsz,wght@0,8..60,400;0,8..60,600;1,8..60,400;1,8..60,600&family=Source+Code+Pro:wght@400;500&family=Caveat:wght@500&family=LXGW+WenKai+TC:wght@400&family=Noto+Sans+TC:wght@400;500;700&family=Noto+Serif+TC:wght@500;700;900&display=swap">
```

```css
--f-display:"Source Serif 4","Noto Serif TC",serif;  /* 英文大標（中文自動落到思源宋體） */
--f-serif:"Noto Serif TC",serif;                     /* 中文標題：思源宋體 */
--f-sans:"Noto Sans TC","PingFang TC",sans-serif;    /* 內文：思源黑體 */
--f-mono:"Source Code Pro","Noto Sans TC",monospace; /* 日期、時間、小標籤：打字機感 */
--f-hand:"Caveat","LXGW WenKai TC",cursive;          /* 手寫字：只用在照片說明、「隔天」這類點綴 */
```

| 用途 | 字體 | 大小 |
|---|---|---|
| 首頁／旅程大標 | 英文 Source Serif 4 + 中文思源宋體 900 | `clamp(44px,6.4vw,100px)` |
| 區塊標題 | 同上 | `clamp(36px,6vw,72px)`，下方一條 1px 深色線 |
| 小標（kicker） | Source Code Pro，全大寫，字距 .18em | 13px |
| 內文 | 思源黑體 | 16px（手機 15px），行高 1.8 |
| 手寫點綴 | Caveat／霞鶩文楷 | 15–22px |

### 2.3 形狀

- 按鈕、標籤：全部是**膠囊**（`border-radius:999px`）。
  - 深色實心按鈕：底色 `--ink`、字色 `--butter`。
  - 外框按鈕：透明底、1.5px `--ink` 框線。
  - hover 時兩者互換。
- 照片卡片圓角 10px；相紙樣式不加圓角。

## 3. 共用版面元件

### 3.1 頁首
- 固定在最上方，一開始透明，往下捲 40px 後加上半透明底色 `color-mix(in srgb,var(--bg) 94%,transparent)` 和模糊效果。
- 左邊是網站名（思源宋體 900）＋一個英文手寫副標，放在米白膠囊裡，蓋在照片上也看得清楚。
- 右邊是膠囊選單，列出各趟旅程；最後一個用深色實心按鈕。
- **手機**：選單收進右上角的「選單」膠囊按鈕，點開是全螢幕、主色底的抽屜，大字列出首頁和各趟旅程。
- ⚠️ **不要做底部分頁列**。我們做過再拿掉了：它的連結只指向某一趟旅程，和「首頁」放在一起會讓人搞混。

### 3.2 分割大圖（首頁、旅程頁、每天的頁面都用）
- 左半邊滿版照片，右半邊主色塊。
- 色塊上依序放：小標 → 大標 → 一段等寬字說明 → 膠囊按鈕。
- 首頁的色塊右下角，再疊一張直式小照片。
- 手機改成上照片、下色塊。

### 3.3 資訊條
- 大圖下方一條深色（`--ink`）橫條，分 4 格：出發日期、住宿、人數、天數。
- 手機改成 2×2。

### 3.4 旅程卡片（首頁）
- **一張封面照**，比例 4:3，圓角 10px。
- ⚠️ 不要做三張拼貼：手機上色調落差太大，會很跳。
- 卡片下方：
  - 左邊：旅程名（思源宋體）＋路線
  - 右邊：大編號 `01`（Source Serif 4）
  - 再往下：灰色等寬字的日期與天數，和一個手寫斜體的連結「翻照片日記 →」

### 3.5 首頁結構
1. 分割大圖（大標 + 一句介紹 + 兩個按鈕）
2. 數字列：幾趟、幾天、幾個地點、幾張照片，用大的 Source Serif 數字
3. 「下一趟旅程」大卡片，給規劃中的旅程用
4. 已經去過的旅程卡片
5. 半版圖文介紹區
6. 照片牆（瀑布流，點開放大）
7. 深色頁尾，網站名放超大字

## 4. 旅程頁的兩種模式

依旅程的狀態自動切換：**已結束**用「回憶故事書」，**規劃中**用「行前資訊」。

### 4.1 已結束：回憶故事書

| 段落 | 內容 | 設計重點 |
|---|---|---|
| **序 Prologue** | 一句話開場，例如「一家四口，四天，走過金門、中山路和南普陀寺。」，由資料自動組出人數、天數和每天的區域；使用者另外寫的回憶接在下面 | 背景是旅程大圖，透明度 .16，放射狀漸隱 |
| **每天一章 Chapter** | 大字「第一天」＋手寫「Chapter 01」＋日期、區域、標題、使用者寫的這天回憶（選填）＋「當天的行程」連結 | 見下方「章節做法」 |
| **隔天** | 章與章之間一條往下淡出的細線，加手寫「隔天」 | 銜接感 |
| **旅途中的小片段** | 沒歸到哪一天的照片，散放的相片卡 | |
| **尾聲 Epilogue** | 三張相片疊在一起，加上「〇〇，就收在這裡。」＋天數、地點、照片數＋「下一站：（下一趟旅程）→」 | 收尾，也接到下一趟 |

之後再依序放「我們去過的地方」（區域卡片）、精簡的「當時的行程」清單、預設收合的「當時的行前準備」。

**章節做法**
- **底色遞進**：第一章是暖米色 `#F8F0E3`，最後一章是霧藍 `#E3E9EC`，中間依比例混色，越往下越安靜。
- **淡化背景**：每章上方用當天主照片做背景。

  ```css
  opacity:.2; filter:blur(2px) saturate(.7) sepia(.2);
  mask-image:linear-gradient(#000,transparent);
  ```

- **串連的細線**：電腦版每章左側有一條 1px 細線，章節標題旁一個空心小圓點，把各章串起來。

### 4.2 規劃中：行前資訊（給要一起去的人看）

> 我們原本的對象是媽媽，福岡是朋友一起去，模組請依朋友的需求調整。

- **每天集合時間（大字版）**
  - 每天一列：左邊日期，右邊幾個淺色圓角塊。
  - 每塊是大號時間（Source Serif，34–48px）＋說明（18–21px）。
  - 只列要準時到的時間，依時間排序。
- **特別需求的店家整理**：我們是「媽媽可以吃的素食店」，依區域整理，附「在地圖開啟」按鈕。福岡可以換成大家想吃的店、需要預約的店等。
- 之後是每日行程（照片和文字左右交錯）、輪播的旅行小叮嚀、景點與店家、實用資訊（可收合）。

## 5. 照片規則（最重要）

1. **照片依行程歸到每一天**
   - 照片連結的地點，出現在哪一天的行程裡，就歸到哪一天；同一天的照片照行程先後排。
   - 每天的主照片固定是那天的橫幅照片。
   - 同一張照片不在兩天重複出現。
2. **滿版或留白，看照片方向**
   - 主照片是橫向（寬高比大於 1.15），就整幅滿版、不加框。
   - 主照片是直向，但當天有橫向照片，就換那張上來滿版。
   - 不連續兩天滿版。
   - 其他天留白，主照片輪流用四種樣式：
     - **相紙**：白底，照片下方有暖色陰影，手寫說明放在相紙下緣。
     - **底片黑框**：白底，照片外加 6–10px 黑框。
     - **霧化背景**：同一張照片模糊當背景，蓋一層白霧（.52），上面放黑框照片。
     - **手寫字**：照片上直接用白色手寫字寫說明，左下角寫手寫日期。
   - 只有一張照片的那天，就單張擺放，旁邊留白。
   - 建議每張照片在資料裡存一個寬高比 `r`，不用載入大圖就能判斷橫直。
3. **小相片**
   - 最多 4 張，混搭無框、白邊、白邊加黑框三種，下方手寫說明。
   - 微微傾斜（−1.8° 到 1.8°），滑過時擺正並浮起。
   - 暖色陰影：`0 1px 2px rgba(80,55,30,.08), 0 16px 30px -18px rgba(80,55,30,.5)`。
   - 超過 5 張就收進「還有 N 張・看全部 →」，點開燈箱可以左右滑。
4. **色調**
   - 一般照片用淡淡的底片調：`filter:saturate(.82) contrast(.95) brightness(1.04) sepia(.12)`。
   - **食物照片一定要暖亮**，看起來才好吃：`filter:brightness(1.1) saturate(1.18) contrast(1.04) sepia(.08) hue-rotate(-4deg)`。
   - 用照片說明判斷是不是食物（有麵、粥、咖啡、茶、甜點等字），但「店門口、樓梯、招牌、街景」這類不算。燈箱放大時也要套同樣的色調。

## 6. 不要做的事（我們踩過的雷）

- ❌ 三張照片拼成一個封面：色調不一致，很跳。
- ❌ 手機底部分頁列：容易搞混。
- ❌ 每張照片都套同一種相框：太制式，要有滿版和留白的節奏。
- ❌ 食物照片套灰色底片調：看起來不好吃。
- ❌ 中文和英文用不同家族的字體（例如 Bodoni 配思源宋體）：風格會打架。
- ❌ 自行編造回憶文字或行程事實：只用資料裡有的內容，其他留欄位讓使用者自己寫。
