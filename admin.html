家族旅行後台

用 GitHub 金鑰登入。金鑰只存在這台電腦的瀏覽器，不會傳給其他人。

還沒有金鑰？3 分鐘建立
  1. 打開 GitHub 建立金鑰頁面
  2. Token name 填「家族旅行後台」，Expiration 選 1 年
  3. Resource owner 選 tabi-log
  4. Repository access 選 Only select repositories → family-travel
  5. Permissions → Repository permissions → Contents 設為 Read and write
  6. 按 Generate token，複製 github_pat_ 開頭那串貼到上面
